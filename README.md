# VaiPet

Plataforma completa para gestão de pets, conectando tutores e profissionais petwalkers de forma segura e eficiente.

## Stack

- TanStack Start (React 19, Vite 7) — SSR + server functions.
- Tailwind CSS v4 + shadcn/ui.
- Vercel — Hosting e Edge Runtime.
- Supabase — Auth, Postgres com RLS, Storage.

## Desenvolvimento

Padronizado para **npm**.

```bash
npm install
npm run dev
```
